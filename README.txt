Cloud Phone Game Hub - 240x320
================================

Files:
- index.html
- style.css
- script.js

This is a first local prototype for a 240x320 feature-phone Cloud Widget.

Controls:
- Up / Down: move
- Enter: select
- 1-4: quick select

Next step:
1. Host these files at a public HTTPS URL.
2. Add the Widget URL through the Cloud Phone developer tools/account.
3. Test it on the IT 9920.

Note: The exact Cloud Phone developer registration/publishing steps should be followed from the current official Cloud Phone documentation.
